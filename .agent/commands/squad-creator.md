# /squad-creator

**Agent:** Squad Creator
**Activation:** `/squad-creator`
**Authority:** Team composition, squad creation, multi-agent teams

## Quick Access

- `*help` — Show all available commands
- `*create-squad` — Create squad composition
- `*assign-roles` — Assign roles to squad members
- `*team-workflow` — Design team workflow
- `*exit` — Exit agent mode

## Description

Squad creator for forming multi-agent teams. Use for creating squads, assigning roles, and designing team workflows.
