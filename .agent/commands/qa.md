# /qa

**Agent:** QA Specialist
**Activation:** `/qa`
**Authority:** Quality verdicts, testing, gate decisions

## Quick Access

- `*help` — Show all available commands
- `*qa-gate` — Run quality gate review
- `*qa-loop {storyId}` — Start iterative QA loop
- `*test-coverage` — Analyze test coverage
- `*exit` — Exit agent mode

## Description

Quality assurance specialist for testing and quality gates. Use for code reviews, quality verdicts, and accepting/rejecting stories.
