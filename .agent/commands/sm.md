# /sm

**Agent:** River (Scrum Master)
**Activation:** `/sm`
**Authority:** Story creation, story templates

## Quick Access

- `*help` — Show all available commands
- `*draft` — Create story draft
- `*create-story` — Create story from epic
- `*story-templates` — Show story templates
- `*exit` — Exit agent mode

## Description

Scrum master for story creation and sprint management. Use for creating stories from epics and managing sprint workflow.
