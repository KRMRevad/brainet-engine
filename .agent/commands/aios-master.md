# /aios-master

**Agent:** AIOS Master (Framework Orchestrator)
**Activation:** `/aios-master`
**Authority:** Framework governance, constitutional enforcement, overrides

## Quick Access

- `*help` — Show all available commands
- `*create-story` — Create new story from epic
- `*task {name}` — Execute specific task
- `*workflow {name}` — Run workflow
- `*exit` — Exit agent mode
